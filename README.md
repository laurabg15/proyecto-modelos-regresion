# Predicción del Precio de Viviendas – House Prices

Proyecto **Modelos y Simulación de Sistemas I** (2026-II).

## Integrantes del equipo
- Laura Vanessa Botero Gil
- Duban Lopez Sanchez

## Problema
Estimar el precio de venta (`SalePrice`, en USD) de viviendas residenciales en Ames, Iowa, a partir de sus características. Es un problema de **aprendizaje supervisado de regresión**. Datos de la competencia de Kaggle [House Prices – Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data).

## Organización del repositorio
| Carpeta | Contenido |

| [`fase-2/`](fase-2/) | Entrega 2: scripts de entrenamiento y predicción, versionamiento del modelo, Docker y pruebas con pytest. |

Cada carpeta tiene su propio `README.md` con las instrucciones para ejecutarla.
